# karmaflix

Projet de site web développé avec Codex.

## Utilisation rapide

1. Télécharge ou clone ce dépôt puis ouvre simplement `index.html` dans ton navigateur.
2. Si la page affiche du texte brut avec des signes `+`/`-` ou un en-tête `diff --git`, c'est que le fichier enregistré est un patch et non la vraie page : récupère à nouveau le fichier `index.html` de ce repo puis remplace ta copie locale.
3. Aucune installation n'est nécessaire : tout fonctionne en local, y compris l'aperçu en direct et la sauvegarde des films via `localStorage`.
